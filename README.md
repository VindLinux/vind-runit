# vind-runit

Utilities and scripts for [runit](https://smarden.org/runit) used by Vind.

## Installation

Clone the repository and install the utilities:

```sh
git clone https://github.com/VindLinux/vind-runit
cd vind-runit
```

Install:

```sh
./install.sh
```
